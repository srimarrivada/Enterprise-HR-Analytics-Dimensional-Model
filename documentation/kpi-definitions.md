# KPI Definitions

| KPI | Formula |
|---|---|
| Headcount | Count of active workers as of snapshot date |
| Attrition Rate | Terminations / Average headcount |
| New Hire Count | Count of hire events |
| Internal Movement Rate | Worker movement events / Average headcount |
| Training Coverage | Workers enrolled or completed training / Active workers |
| Average Tenure | Average months between hire date and snapshot date |
