# Grain Definitions

| Table | Grain |
|---|---|
| FACT_HEADCOUNT_SNAPSHOT | One row per worker per snapshot month |
| FACT_WORKER_EVENT | One row per worker lifecycle event |
| FACT_HIRE | One row per hire event |
| FACT_TERMINATION | One row per termination event |
| FACT_COMPENSATION | One row per worker per compensation plan/effective period |
| FACT_PERFORMANCE | One row per worker per review cycle |
| FACT_LEARNING_ENROLLMENT | One row per worker per learning session |
